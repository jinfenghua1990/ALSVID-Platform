# ALSVID Platform

ALSVID 品牌数字化平台（开发阶段）

## 当前定位

一个统一平台，后期根据部署需求拆分不同访问入口。

## 核心模块

### 1. 官网商城（Shopify）
- 品牌展示
- 产品展示
- 在线销售

### 2. B2B 经销商系统
- 经销商登录
- 产品目录
- 批量订货

### 3. ALSVID Platform
- 产品中心
- 售后中心
- 客户车辆档案
- 经销商管理

### 4. Commerce 模块
- 订单
- 采购
- 库存
- 财务数据接口

## 开发原则

目前统一在一个代码库开发。

未来部署时根据权限和安全需求拆分：

- admin.alsvid.com
- dealer.alsvid.com
- service.alsvid.com
- api.alsvid.com
