# ALSVID Platform 模块架构

## 目标
当前阶段使用一个 GitHub 仓库统一开发，后续部署时再拆分不同访问入口。

## 核心模块

### 1. 产品中心
- 产品主数据
- 技术参数
- 版本管理
- BOM关联
- 配件关联
- 多语言资料

### 2. 售后中心
- 客户车辆档案
- 保修管理
- 维修工单
- 配件申请
- 维修进度通知

### 3. 客户中心
- 客户资料
- 购买记录
- 车辆绑定
- 服务历史

### 4. 经销商中心
- 经销商资料
- B2B订单需求
- 技术资料
- 售后协作

### 5. 商业运营中心
- 订单
- 采购
- 库存
- 财务接口

### 6. 系统中心
- 用户
- 角色
- 权限
- 多语言
- API接口
