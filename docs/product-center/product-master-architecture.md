# ALSVID 产品中心（Product Master）设计

## 核心原则

所有渠道只使用一套产品主数据（Product Master）。

数据来源：产品中心。

调用方：
- 官网 Shopify
- B2B 经销商端
- 售后系统
- 内部管理后台

## 产品层级

产品：FC1

```
产品系列
  ↓
平台型号
  ↓
配置版本
  ↓
SKU
  ↓
零部件/BOM
```

## 产品基础字段

### 基础信息
- 产品名称
- 平台型号
- 产品分类
- 状态（研发/量产/停售）
- 上市时间
- 目标市场

### 技术参数
- 车架材质
- 电机型号
- 电池容量
- 续航
- 重量
- 尺寸
- 颜色

### 商业字段
- 销售状态
- 官网展示状态
- B2B展示状态
- 售后可用状态

### 工程字段
- BOM
- 配件关系
- 技术文件
- 版本记录

## 页面设计

产品详情页：

1. 基础信息
2. 参数配置
3. 图片视频
4. BOM结构
5. 配件关系
6. 技术资料
7. 版本变更
8. 销售渠道

## 目标

一个产品数据，支撑整个 ALSVID 生态。
