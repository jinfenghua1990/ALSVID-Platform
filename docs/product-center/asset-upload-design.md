# ALSVID 产品素材上传设计

## 目标

商品创建时支持拖动上传素材，素材进入统一 Asset Center，不直接存储在商品数据中。

## 上传方式

支持：

- 拖拽图片上传
- 批量上传
- 图片预览
- 自动压缩
- 自动生成缩略图
- 文件标签分类

## 素材分类

FC1 示例：

```
FC1
├── 产品主图
├── 产品详情图
├── 场景图
├── 视频
├── 技术文件
├── 维修资料
└── 经销商资料
```

## 数据关系

```
Product Master
      |
      |
Asset Center
      |
      |
Object Storage
```

商品只保存素材ID，不保存文件本身。
