# ALSVID SOP 标准框架

## 目的
建立 ALSVID 企业运营标准，将碎片化业务知识沉淀为可执行、可培训、可系统化的标准流程。

## ALSVID SOP 分类

- 产品管理 SOP
- SKU编码 SOP
- 素材管理 SOP
- 供应链 SOP
- 采购 SOP
- 出口 SOP
- 经销商管理 SOP
- 售后服务 SOP
- 客户生命周期 SOP
- 系统操作 SOP

## 编写原则

1. 先业务确认，再系统开发。
2. 一个数据源原则：产品、客户、车辆等只维护一份。
3. SOP最终需要可以转化为系统功能。
4. 所有重大流程需要版本管理。
