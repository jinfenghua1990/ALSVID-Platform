# ALSVID Asset Center Storage Architecture

## 目标

统一管理 ALSVID 产品图片、视频、PDF、维修资料等素材。

## 核心原则

- 素材独立于产品数据
- 产品只关联素材ID
- 存储方式可替换

## 架构

```
上传文件
  ↓
ALSVID Asset Center
  ↓
对象存储（R2 / OSS / COS / S3）
  ↓
CDN访问
  ↓
官网 / B2B / 售后系统
```

## 上传流程

1. 用户拖拽上传文件
2. 系统生成素材记录
3. 上传至对象存储
4. 返回文件URL
5. 绑定产品、用途和权限

## 素材分类

- 产品主图
- 产品详情图
- 场景图片
- B2B销售资料
- 售后维修资料
- 用户手册
- 视频文件

## 后续支持

- 批量上传
- 自动缩略图
- 图片版本管理
- AI素材识别
- 多语言标签
